# 更新记录

本文件记录 Karina's Corner 的版本更新。版本标签与 GitHub Releases 保持对应。

## 当前功能概览

- Hello Kitty 风格首页与 Karina 专属小狗熊。
- 特伦托交换行程：日历、航班、火车、酒店、时区及实时天气。
- Google 地图与地点详情：搜索联想、地点卡片、路线方案、步行/驾车/骑行/公共交通、全屏查看。
- 食住行等生活信息模块与后续扩展入口。
- 小游戏室与 `开局托儿所`：自由框选数字、凑十消除、单局学历成长、游戏次数及狗熊亲亲动画。
- 电脑与手机端响应式布局。

## Unreleased

- 优化 `开局托儿所` 的选框与空格计数规则。
